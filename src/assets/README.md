# Assets Guide for Githendra

Drop your visual assets directly here:

1. **Professional Headshot**:
   - Save your headshot image as `src/assets/images/headshot.jpg` (or `.png`).
   - The hero section is prepared with an avatar frame and will display your photo.

2. **Project Screenshots**:
   - Save 16:9 or 4:3 screenshots for each project inside `src/assets/images/`:
     - `candeur-crescent.png` (Real Estate Website)
     - `banking-system.png` (Banking System Full-Stack Java)
     - `hostel-hub.png` (Hostel Management System)
     - `bibliostack.png` (Bibliostack React Book Manager)

3. **Resume PDF**:
   - Place your official PDF as `public/resume.pdf`.
   - The "View Resume" & "Download PDF" buttons will automatically download/open this file.
